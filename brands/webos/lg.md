# LG (webOS) — same shape as Samsung, different tooling

LG TVs run webOS, not Android: no ADB, no replacement launcher.

- Developer mode app → enable → use the webOS CLI (`ares-install`,
  `ares-launch`) to manage apps where the TV allows it.
- Settings: turn OFF Live Plus (ACR) and personalized ads.
- DNS-level blocking as in `brands/tizen/samsung.md`.
- Record per model + firmware what worked; no universal package list.
