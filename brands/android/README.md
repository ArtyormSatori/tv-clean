# Android TV / Google TV brand packs

These TVs all use the ADB engine (`scripts/` + `tools/`). A brand pack
is a measured bloat list for that brand, verified on a real TV of that
brand — never guessed package names.

- `tcl.md` — TCL (TO MEASURE: no TCL TV has been measured yet; the
  file documents the measurement procedure, not a package list).
- Other Android brands (Sony, Xiaomi, Hisense-Android, Philips-Android,
  Skyworth, Coocaa, ...) reuse the same engine; add a pack per brand
  only after measuring a real unit.
